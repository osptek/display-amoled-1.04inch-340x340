# 示例工程 / Sample Projects

本目录中的每个子文件夹都是一个独立的示例工程，请进入对应文件夹后按照其中的 README 进行编译。这些工程是参考代码，引脚、背光、触摸等配置请根据实际硬件修改。选用前请对照仓库首页各型号的驱动 IC 和接口进行确认。

Each subfolder in this directory is an independent example project. Open the folder and follow its README to build. These projects are reference code only — please modify pin assignments, backlight, touch, and other settings according to your actual hardware. Before use, verify the driver IC and interface against the model information on the repository home page.
